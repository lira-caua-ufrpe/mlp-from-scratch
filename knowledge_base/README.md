## 🎯 Princípios Norteadores do Projeto

1. **Abordagem Não Diagnóstica:** O sistema é uma ferramenta de auxílio situacional e alerta precoce para o professor e mediador, nunca um substituto do diagnóstico clínico multidisciplinar.
2. **Privacidade Absoluta (Edge Computing):** Os dados de vídeo da criança são processados no dispositivo em memória volátil e descartados imediatamente após a extração das coordenadas dos pontos anatômicos.
3. **Ponte Tripartite:** Unir os dados empíricos observados na sala de aula com a prática clínica dos psicólogos (ABA/TCC) e a gestão pedagógica da escola.
